# Lalu

App navigasi buatan Malaysia: kos tol dan minyak setiap laluan, mod motosikal, hentian solat dan R&R sepanjang jalan.

- `index.html` — landing page dan borang pendaftaran beta
- `beta/` — prototaip web app (peta, laluan, navigasi, laporan, hentian)
- `apps-script.gs` — skrip Google Apps Script untuk simpan pendaftaran ke Google Sheet

Laman: https://afiq97972.github.io/lalu/
